# Program Swap Quick Reference Guide

## For Staff Using Single-Enroll

### When to Use Program Swap
- Student requests program change
- Student has been reassigned to different program
- Correcting enrollment errors
- Academic progression requires program change

### Normal Enrollment Steps
1. Select student from dropdown
2. Choose session, semester, section
3. Select subjects
4. Click "Enroll" button
5. Review confirmation and confirm

### Program Change Steps
1. Select student from dropdown
2. **Change the Program dropdown** (different from current program)
3. **⚠️ Warning banner appears - READ CAREFULLY**
4. **System automatically checks:**
   - Unpaid fees
   - Currently enrolled subjects
   - Exam marks already recorded
   - Attendance records
   - Active payment plans
   - Credit limit differences
5. **Review ALL warnings displayed** (in colored alert boxes)
6. **Provide detailed reason** in the "Program Change Reason" field
   - Be specific
   - Explain why change is necessary
   - This is recorded for audit purposes
7. Choose session, semester, section (for new program)
8. Select subjects (relevant to new program)
9. Click "Enroll" button
10. **Enhanced confirmation modal appears with:**
    - Red header (indicates program change)
    - All warnings repeated
    - Your reason displayed
    - Standard checks
11. Review everything carefully
12. Click "Confirm Enrollment"

### Warning Types

#### 🔴 HIGH PRIORITY (Red Alerts)
- **Unpaid Fees**: Student has outstanding fees - coordinate with finance
- **Enrolled Subjects**: Student has subjects in progress - may lose credits
- **Exam Marks**: Grades already recorded - contact registrar
- **Payment Plans**: Active installment plans - may need adjustment

#### 🟡 MEDIUM PRIORITY (Yellow Alerts)
- **Pending Payments**: Verification needed - check with finance
- **Attendance Records**: Attendance tracked - inform faculty
- **Assignments**: Submissions exist - notify instructors

#### 🔵 INFORMATIONAL (Blue Alerts)
- **Credit Limit Change**: Max credits per semester differs
- **Faculty Change**: Student moving to different faculty
- **Program Details**: Shows old and new program names

### Important Notes

✅ **DO**:
- Read all warnings carefully
- Provide detailed, meaningful reasons
- Coordinate with relevant departments (finance, registrar)
- Verify student understands implications
- Document any student requests
- Check if subjects can transfer

❌ **DON'T**:
- Ignore warnings
- Use generic reasons ("student request", "need to change")
- Process without checking unpaid fees
- Skip coordination with other departments
- Rush the process

### Good Reason Examples

✅ **GOOD**:
> "Student completed Certificate in Theology and is now progressing to Diploma in Theology as per normal academic pathway. All prerequisites met. Student has paid all fees for certificate program."

> "Student initially enrolled in wrong program due to application error. Correct program should be Bachelor of Arts in Religious Education based on student's transcripts and admission letter dated [date]."

> "Program change approved by Academic Board meeting on [date]. Student demonstrated exceptional performance in Bible Studies and requested transfer from Certificate to Advanced Diploma. Dean approval reference: [ref-number]."

❌ **BAD**:
> "Student wants to change"

> "Mistake"

> "Program change"

### After Program Change
- Student record updates automatically
- Previous program stored in history
- Your reason saved permanently
- Audit trail created
- Success message confirms change

### If Problems Occur
1. Check all warnings were reviewed
2. Ensure reason was provided
3. Verify program selection is correct
4. Confirm session, semester, section match new program
5. Check subjects are valid for new program
6. Contact IT support if technical error

### FAQ

**Q: Can I change program without providing a reason?**
A: No, the system requires a detailed reason for audit purposes.

**Q: What if student has unpaid fees?**
A: Warning shown but you can proceed. Coordinate with finance department first.

**Q: Will student lose enrolled subjects?**
A: Previous enrollment becomes inactive. Subjects from old program won't automatically transfer.

**Q: Can I undo a program change?**
A: Contact IT support immediately. May require manual database adjustment.

**Q: Do subjects need to be re-selected?**
A: Yes, select subjects appropriate for the NEW program.

**Q: What about credit limits?**
A: System shows if new program has different credit limit. It enforces the new limit.

**Q: Is student notified?**
A: Not automatically. You should inform the student of the change.

**Q: Where is the history stored?**
A: All changes logged in enrollment records with timestamps and your reason.
